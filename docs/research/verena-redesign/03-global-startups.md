# Global startups — category context

Confidence: **moderate** for the category framing, **low** for any specific
funding numbers (none were verified — see gaps below).

## The category Verena sits in
"AI agent + human-in-the-loop" compliance/GRC (governance, risk, compliance)
is now an established, named category, not a novelty Verena invented:

- **Vanta, Drata, Secureframe, Sprinto, Scrut** — AI-assisted SOC2/ISO27001
  compliance automation for security teams at mid-market/enterprise
  companies.
- **Harvey** — AI for legal work more broadly (not website compliance
  specifically, but the same "AI agent handling legal/compliance judgment
  with professional oversight" framing).
- Forrester has reportedly begun scoring GRC vendors against an explicit
  **"AI Agents" evaluation criterion** — meaning buyers and analysts already
  expect and reward this framing, rather than treating it as a red flag.

## Why this matters for Verena
Verena can lean into "AI agent + human backstop" as a confident, legitimate
category claim in its copy and design, rather than hedging it as something
novel or risky. The category normalization already did that work. This also
means avoiding generic "AI startup" visual clichés (the hero-metric template,
gradient text, glass cards) actively *hurts* Verena here — it would make a
now-credible category read as a trend-chaser instead.
