# Top tech company benchmarks

Confidence: **low-to-moderate, design judgment** — this list was not produced
by fresh, sourced research this round. Arc's and Linear's general design
language is well known publicly, but no current brand-page fetch backs the
specifics here. Ramp and Mercury were searched for and returned no usable
source material — they're listed as a gap, not a finding.

## Why these companies
Verena is competing for attention against both generic "legal SaaS" (boring,
form-heavy, blue-and-grey) and generic "AI startup" (gradient-on-black,
hero-metric template) aesthetics. The useful benchmarks are companies that
escaped both reflexes while still reading as a serious, trustworthy tool for
something consequential (money, in fintech's case; infrastructure, in
Linear's case).

## Linear
Restrained typographic minimalism, confident dark-mode-native UI, and
unusually careful motion easing. Useful benchmark for "serious tool, not
enterprise-stiff" — closest match to the brief's "interactive, motion, but not
messy" constraint.

## Arc (The Browser Company)
Soft gradients, editorial copy voice, playful without being juvenile. Closest
public analogue to the blurred-gradient-cloud panel already built into
`VerenaHero.tsx`.

## Stripe
The reference case for blending technical credibility with warmth — relevant
because Verena is also asking a non-technical owner to trust it with something
sensitive (their site's legal exposure), the same trust problem fintech
onboarding solves for money.

## Gap: Ramp / Mercury
Intended as fintech benchmarks for "serious money, friendly brand" — no usable
source material came back for either company's actual current design language
in this research pass. Don't cite specifics from these two; if they matter,
they need a dedicated look (screenshots of the live sites), not a web search.

## Takeaway
Use these as taste references, not prescriptive specs. None of this is a
substitute for looking at Verena's own existing design decisions (already
cream/maroon/yellow, already serif headline) and tech-benchmarking the
*execution quality* (motion restraint, type hierarchy, whitespace discipline)
rather than borrowing their visual identity.
