# Verena AI

Marketing site for Verena, built with React, TypeScript, and Vite.

## Development

```bash
pnpm install
pnpm dev
```

## Build

```bash
pnpm build
```

Builds a type-checked production bundle to `dist/`.

## Deployment

Deployed on Vercel. `vercel.json` configures the build command, output directory, and SPA rewrites for client-side routing.
